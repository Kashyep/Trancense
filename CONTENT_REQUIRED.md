# Content required before launch and pitch

Use this as the single intake worksheet. Do not publish an item until it is approved, factual, and owned. The public UI intentionally shows provisional copy rather than fabricated proof.

## 1. Brand and identity

| Required input | Readiness |
| --- | --- |
| Final public product name and spelling; production domain | Required before public launch |
| SVG logo, favicon, light/dark variants if needed, and brand-mark usage rules | Required before public launch |
| Approved Exo 2, Open Sans, and Kanit font choice/license confirmation, or approved fallbacks | Required before public launch |
| Company/legal name; contact email; support email; social links | Required before public launch |
| Founder/team names, roles, bios, headshots, and LinkedIn links | Required before investor pitch |

## 2. Public landing-page content

| Required input | Readiness |
| --- | --- |
| Final headline and supporting statement | Required before public launch |
| CTA labels, destinations, and contact/request-pilot workflow | Required before public launch |
| Product feature priorities, target industries/facility types, target customer titles, and geographic scope | Required before public launch |
| Real product screenshots or approved mockups; approved demo-environment details | Required before public launch |
| FAQ questions and approved answers; final footer copy | Required before public launch |

## 3. Proof and trust

| Required input | Readiness |
| --- | --- |
| Real customer/partner logos with written permission | Optional future enhancement |
| Approved customer count, only if factual | Optional future enhancement |
| Testimonials with name, role, organization, date, permission, and exact approved quote | Optional future enhancement |
| Case studies with baseline, scope, methodology, measurable result, caveats, and permission | Required before investor pitch |
| Verified press, grants, awards, accelerators, or affiliations | Optional future enhancement |
| Security/privacy claims that can be substantiated; approved regulatory/standards references, if any | Required before public launch |

## 4. Product and pilot readiness

| Required input | Readiness |
| --- | --- |
| Exact features available at launch and features intentionally excluded from the pilot | Required before customer pilot |
| Supported energy sources/units; approved factor/tariff source hierarchy; factor and tariff versions | Required before customer pilot |
| Data-retention/deletion policy and data-residency position | Required before customer pilot |
| AI provider, model, customer-data handling terms, retention policy, and consent stance (if AI is enabled) | Required before customer pilot |
| Support and incident-response contact; pilot onboarding and success criteria | Required before customer pilot |
| Pricing approach, only if ready for public presentation | Required before investor pitch |

## 5. Pitch-ready investor/customer materials

| Required input | Readiness |
| --- | --- |
| Problem statement backed by credible source or customer evidence | Required before investor pitch |
| Ideal customer profile and buyer/user personas | Required before investor pitch |
| Market definition and cited market-size inputs | Required before investor pitch |
| Competitive alternatives and positioning | Required before investor pitch |
| Pilot traction, pipeline, and customer-discovery evidence | Required before investor pitch |
| Business model and pricing hypothesis; go-to-market plan | Required before investor pitch |
| Founder-market fit/team credentials and product roadmap | Required before investor pitch |
| Funding ask, use of funds, runway, and milestones, if investor-facing content is desired | Required before investor pitch |
| Real demo script, demo-data policy, and metrics that can be publicly stated without misleading users | Required before investor pitch |

## 6. Legal, privacy, and operations

| Required input | Readiness |
| --- | --- |
| Privacy policy text approved by counsel; terms of service; cookie policy/consent requirements; data-processing terms | Required before public launch |
| Incident-response contact and escalation process; security contact | Required before customer pilot |
| Company address and jurisdiction | Required before public launch |
| Accessibility contact/process | Required before customer pilot |
| Approved Vercel/Supabase deployment contacts and ownership | Required before customer pilot |
