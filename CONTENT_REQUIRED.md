# Content required before launch and pitch

Use this as the single intake worksheet. Do not publish an item until it is approved and factual.

## 1. Brand and identity

| Item | Readiness |
| --- | --- |
| Final public product name and spelling; domain | Required before public launch |
| SVG logo, favicon, light/dark variants, brand-mark rules | Required before public launch |
| PolySans license/files or approved fallback | Required before public launch |
| Company/legal name; contact and support email; social links | Required before public launch |
| Founder/team names, roles, bios, headshots, LinkedIn links | Required before investor pitch |

## 2. Public landing-page content

| Item | Readiness |
| --- | --- |
| Final headline, supporting statement, CTA labels/destinations | Required before public launch |
| Contact/request-pilot workflow and owner | Required before customer pilot |
| Feature priorities, industries/facility types, customer titles, geographic scope | Required before public launch |
| Approved product screenshots/mockups and demo environment policy | Required before public launch |
| FAQ questions/answers and footer copy | Required before public launch |

## 3. Proof and trust

| Item | Readiness |
| --- | --- |
| Customer/partner logos with written permission | Optional future enhancement |
| Factual customer count | Optional future enhancement |
| Approved testimonials: name, role, organization, date, permission, exact quote | Optional future enhancement |
| Case studies: baseline, scope, method, result, caveats, permission | Required before investor pitch |
| Verified press, grants, awards, accelerators, affiliations | Optional future enhancement |
| Substantiated security/privacy and regulatory/standards claims | Required before public launch |

## 4. Product and pilot readiness

| Item | Readiness |
| --- | --- |
| Exact launch features and deliberately excluded pilot features | Required before customer pilot |
| Supported energy sources/units; factor/tariff hierarchy and versions | Required before customer pilot |
| Retention/deletion policy and data residency position | Required before customer pilot |
| AI provider/model/data terms/retention/consent stance, if AI is enabled | Required before customer pilot |
| Support and incident-response contact; pilot success criteria | Required before customer pilot |
| Pricing approach | Required before investor pitch |

## 5. Pitch-ready material

| Item | Readiness |
| --- | --- |
| Cited problem evidence; ICP and buyer/user personas | Required before investor pitch |
| Cited market definition/size; competitive alternatives | Required before investor pitch |
| Pilot traction, pipeline, discovery evidence; business model and GTM | Required before investor pitch |
| Founder-market fit, roadmap, funding ask/use/runway/milestones | Required before investor pitch |
| Real demo script, demo-data policy, factual public metrics | Required before investor pitch |

## 6. Legal, privacy, operations

| Item | Readiness |
| --- | --- |
| Counsel-approved privacy policy, terms, cookie policy, DPA | Required before public launch |
| Incident/security/accessibility contact and escalation process | Required before customer pilot |
| Company address, jurisdiction, and deployment ownership contacts | Required before public launch |
